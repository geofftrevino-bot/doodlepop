# Fix-It Farm — SHORTS CATALOG (check before writing a new Short)

Every Short made so far, by what it's *about*. **Before scripting a new Short,
read this page and run the duplicate check below.** Short 21 repeated Short 14
(Sprocket, the tractor, a loose bolt, tighten it) and cost ~$4.90 before anyone
noticed. Add each new Short here in the same PR that adds its folder.

## The duplicate check (step 0 of THE PLAYBOOK)

A new idea is a **duplicate** — pick another — if it shares **two or more** of
these with any Short below:

1. **Same lead** character
2. **Same problem** (what's wrong / what the question is)
3. **Same fix or answer** (what they do about it)
4. **Same lesson** (what a child takes away)
5. **Same hero prop or set-piece** (the tractor, a sunflower, a carrot…)

Also check the **Retired** list: those premises are used up for that
character, whatever the wording. Say the check out loud in the plan you show
the user ("closest existing: Short 14 — different because …").
